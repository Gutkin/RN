# FRAME — Android preview

Первое Android-приложение по концепции FRAME: React Native + TypeScript, нативный видеомодуль Kotlin / Android Media3.

## Возможности 0.1.0

- Главная, поиск и фильтрация пяти шаблонов, редактор, один локальный проект и экспорт.
- Один видеоклип, пять вариантов заголовка, чёрно-белый вариант Film Diary.
- Обрезка фрагмента от 1 до 30 секунд, центрированное заполнение вертикального кадра, отключение исходного звука.
- Предпросмотр и экспорт используют один набор нативных эффектов.
- MP4, H.264/AAC, 1080 × 1920, до 30 кадров/с. Сохранение через MediaStore в Movies/FRAME.
- Импорт через системный выбор файла: приложению не нужен доступ ко всей медиатеке.
- Видео не отправляются на сервер. Импортированные копии и проект хранятся в приватной папке приложения.

Это первая тестовая версия, а не реализация всех 20 концепций. Мультиклип, фотоколлажи, отдельная музыка, свободный монтаж, подписки и iOS пока не реализованы. Карточки используют примеры из исходного дизайн-концепта, а не видео пользователя. На экране экспорта показана обложка исходника; итоговое оформление смотрите в видеопредпросмотре редактора.

## Ограничения

Android 10+ (API 29), ARM64 и x86_64. Исходник: H.264 SDR, не более 1920 по длинной стороне и 1080 по короткой, 60 кадров/с, 60 секунд и 200 МиБ на файл. 4K, HDR и HEVC отклоняются до копирования. Для импорта нужен локальный файл с определяемым размером. Проверяются реальные метаданные и временные метки видеосэмплов. Длительность меньше секунды не принимается.

Приватные копии ограничены суммарно 1 ГиБ; их можно удалить в разделе «О приложении». Очистка не удаляет оригиналы или экспорт из галереи. Для экспорта нужно минимум 350 МиБ свободного места. Не сворачивайте приложение во время обработки: экспорт отменяется при уходе в фон, частичный временный файл удаляется. Поддержка конкретного кодека и 1080p-экспорта зависит от устройства; ошибки выводятся пользователю.

## Установка APK

**[Скачать предварительный APK для телефона](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-preview.apk)** — около 62 МБ, Android 10+, 64-битный ARM-телефон. Компиляция, подпись, 9 JS-тестов и 4 нативных unit-теста проверены. Эмуляторная проверка запуска/экспорта пока не подтверждена: подробный повторный запуск выполняется в GitHub Actions. Информация об этой сборке: [build-info.json](https://github.com/Gutkin/RN/blob/phone-preview/build-info.json).

Готовые **успешно проверенные CI-сборки** размещаются в отдельной ветке `android-builds`:

- [APK для телефона](https://github.com/Gutkin/RN/raw/refs/heads/android-builds/frame-preview.apk)
- [Результат сборки и SHA исходников](https://github.com/Gutkin/RN/blob/android-builds/result.json)

На телефоне разрешите установку из выбранного браузера или файлового менеджера. Сборка подписана **тестовым ключом**, содержит JavaScript и не требует Metro, Expo Go, аккаунта или сервера.

## Сборка локально

Требуются Node 22, JDK 17, Android SDK platform 35 / build-tools 35.0.0 / NDK 26.1.10909125. `ANDROID_HOME` должен указывать на SDK. Для Maven-зависимостей React Native нужен доступ к `repo.reactnative.dev` (Maven Central перенаправляет туда часть артефактов).

```sh
npm ci
npm run typecheck
npm test
cd android
./gradlew assembleRelease testReleaseUnitTest
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.

На подключённом устройстве или эмуляторе Android 10+:

```sh
cd android
./gradlew connectedReleaseAndroidTest
```

Нативные инструментальные тесты проверяют импорт настоящего H.264, отклонение 4K и реальный экспорт с обрезкой и текстом. Выход повторно декодируется, проверяются разрешение, длительность, видеокодек и отсутствие звука при выключенном аудио. Тесты используют синтетические видеоматериалы в `androidTest/assets`, они не входят в пользовательский APK.

Для разработки с Metro: `npm start`, затем в другом терминале `npm run android` (подключён телефон/эмулятор). Для автономной установки используйте release-вариант.

## Перед Google Play

Текущий APK предназначен для ручного тестирования. До публикации нужны собственная защищённая release-подпись / Play App Signing, проверка действующих требований target SDK и 16-КБ страниц памяти для всех нативных библиотек, обновление зависимостей до поддерживаемых версий, испытания на физических устройствах, политика конфиденциальности и оформление магазина. Тестовый ключ не подходит для выпуска приложения.

## Устройство кода

- `App.tsx` — интерфейс и переходы между экранами.
- `src/templates.ts` — пять шаблонов и примеры для каталога.
- `src/project.ts` — формат проекта, проверка обрезки и восстановление.
- `src/nativeVideo.ts` — типизированный мост React Native → Kotlin.
- `android/.../video/VideoModule.kt` — импорт, ограничения, хранение проекта, экспорт и MediaStore.
- `VideoStyle.kt` — общие эффекты для предпросмотра и экспорта.
- `VideoPreviewManager.kt` — нативный ExoPlayer в редакторе.
- `.github/workflows/android.yml` — сборка, проверки, Android-эмулятор и выдача APK.

Каждая облачная задача уже изолирована. Работайте в существующем checkout `/workspace/RN`; не создавайте Git worktree без запроса пользователя.
