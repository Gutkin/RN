# FRAME — тестовый APK 0.1.0

[Скачать APK для Android 10+](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-preview.apk)

Автономная тестовая сборка: React Native и нативный видеомодуль Kotlin / Android Media3. Размер около 62 МБ, 64-битный ARM-телефон. Для установки разрешите установку из выбранного браузера. Подписано тестовым ключом; для Google Play эта сборка не предназначена.

Проверены подпись, 9 JS-тестов, 4 нативных unit-теста и 3 инструментальных теста на Android 11: отрисовка главного экрана, импорт с отказом для 4K, настоящий экспорт вертикального MP4 с обрезкой, текстом и отключённым звуком. Геометрия экспорта проверяется с учётом MP4-поворота. Отчёт: android-test-report.xml. На физическом телефоне пока не проверялось.

Один клип, пять вариантов оформления заголовка, обрезка и экспорт. Импорт: H.264 SDR, до 1080p, 60 кадров/с, 60 секунд, 200 МиБ. Экспорт: 9:16, до 30 секунд, 1080p, до 30 кадров/с. Коллажи и музыка ещё не реализованы.

SHA-256 и данные о проверках находятся в build-info.json. Исходники — в master.
