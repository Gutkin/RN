# FRAME — предварительный APK 0.1.0

[Скачать APK для Android 10+](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-preview.apk)

Это тестовая сборка с собственным интерфейсом React Native и нативным видеомодулем Kotlin/Media3. APK автономный и подписан тестовым ключом. Для установки разрешите установку из выбранного браузера.

Компиляция и подпись проверены; прошли 9 JS-тестов и 4 нативных unit-теста. Проверка на Android-устройстве пока не подтверждена: эмуляторные тесты ещё выполняются в GitHub Actions. Это не сборка для Google Play.

Один клип, пять вариантов заголовка, обрезка и экспорт. Импорт: H.264 SDR, до 1080p, 60 кадров/с, 60 секунд, 200 МиБ. Экспорт: 9:16, до 30 секунд, 1080p и до 30 кадров/с. Фотоколлажи и музыка ещё не реализованы.

Сверьте SHA-256 в build-info.json. Исходники находятся в ветке master.
