# FRAME 0.1.1 — тестовый APK

[Скачать APK 0.1.1](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-0.1.1.apk)

Установите поверх версии 0.1.0: package ID и подпись совпадают, versionCode увеличен до 2. Android 10+, 64-битный ARM-телефон.

Исправлены вкладки Stories / Reels / Posts, полный коллаж с подписью и заголовком, круглая кнопка, пять индикаторов, свайп и переход в выбранный шаблон. Баннер использует чистую иллюстрацию без встроенных кнопок и текста.

Добавлен импорт HEVC/H.265 SDR при наличии декодера на телефоне; итоговое видео сохраняется в H.264. Ограничения: до 1080p, 60 кадров/с, 60 секунд, 200 МиБ на исходник. HDR и 4K пока не поддерживаются. Экспорт: вертикальное видео до 30 секунд, 1080p, до 30 кадров/с.

Проверены 12 JS-тестов, 7 нативных unit-тестов и 5 тестов на Android 11: переключение вкладок/слайдов и кнопка открытия, импорт H.264 и HEVC, отказ для 4K, настоящий экспорт обоих кодеков в H.264.

[Скриншот приложения](frame-home.png) · [Результаты Android-тестов](android-test-report.xml) · [SHA-256 и данные сборки](build-info.json)

Тестовая подпись; эта сборка не предназначена для Google Play. Физический телефон в автоматических проверках не использовался.
