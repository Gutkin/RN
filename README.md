# FRAME 0.2.0 — Kotlin / Jetpack Compose

[Скачать новый APK](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-0.2.0.apk)

Все экраны, состояние и видеодвижок написаны на Kotlin. В APK нет React Native, Hermes или JavaScript-bundle. Приложение работает автономно на Android 10+.

Установите поверх 0.1.x: package ID и подпись сохранены, versionCode увеличен до 3. Формат project.json версии 1 и приватные видео совместимы с прежней версией. Старый APK 0.1.1 сохранён для проверки обновлений.

Поддерживаются H.264 и HEVC/H.265 SDR до 1080p, 60 кадров/с, 60 секунд, 200 МиБ. Выход: H.264 MP4, 9:16, до 30 секунд, до 30 кадров/с. Ограничения 4K/HDR сохранены.

Проверены 11 unit-тестов и 7 Android-тестов: экраны, карусель, каталог, настоящий плеер, сохранение/повторное открытие проекта, совместимость JSON 0.1.x, импорт, отказ для 4K и экспорт H.264/HEVC. CI устанавливает старый APK и обновление перед проверками.

[Скриншот](frame-home.png) · [Отчёт](android-test-report.xml) · [Данные сборки и SHA-256](build-info.json)

Тестовая подпись; сборка не предназначена для Google Play. На физическом телефоне автоматические проверки не выполнялись.
