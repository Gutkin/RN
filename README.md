# FRAME 0.3.0 — Kotlin / Jetpack Compose

Нативное Android-приложение: все экраны, навигация, состояние и обработка видео написаны на Kotlin. Интерфейс использует Jetpack Compose / Material 3, видеодвижок — Android Media3. Для разработки и сборки нужны JDK и Android SDK.

## Возможности

Главная с вкладками Stories / Reels / Posts, каруселью, пятью индикаторами и кнопкой открытия выбранного шаблона; каталог с поиском и категориями; редактор; один сохраняемый проект; экспорт в галерею. Редактор одного ролика: реальная лента кадров, обрезка двумя границами (1–30 секунд), воспроизведение / пауза и перемотка, точный ввод времени. Вкладки «Текст», «Стиль» и «Звук» позволяют менять заголовок, его положение / размер / цвет, применять чёрно-белый фильтр, заполнять кадр с обрезкой или вписывать целиком с чёрными полями, отключать исходный звук. Настройки работают в предпросмотре и экспорте и сохраняются в проекте. Подборки во всех вкладках рассчитаны на вертикальное видео 9:16.

Исходник: H.264 или HEVC/H.265 SDR, до 1920 по длинной стороне и 1080 по короткой, до 60 кадров/с, 60 секунд, 200 МиБ. Проверяется реальный декодер устройства. 4K и HDR пока не поддерживаются. Экспорт: MP4, H.264/AAC, отображаемые 1080 × 1920, до 30 кадров/с и до 30 секунд. Фото и музыка, несколько клипов и свободный многодорожечный монтаж ещё не реализованы.

Обработка выполняется на телефоне. Исходники не отправляются на сервер. Импортируются приватные копии; их суммарный размер ограничен 1 ГиБ. При уходе в фон обработка отменяется; оставайтесь в приложении до завершения экспорта. Промежуточный файл удаляется, экспорт попадает в `Movies/FRAME` через MediaStore.

## APK и обновление

[Скачать APK 0.3.0](https://github.com/Gutkin/RN/raw/refs/heads/phone-preview/frame-0.3.0.apk) · [Скриншот](https://github.com/Gutkin/RN/blob/phone-preview/frame-home.png) · [Данные о проверках](https://github.com/Gutkin/RN/blob/phone-preview/build-info.json)

Ссылка появляется после публикации проверенной сборки. Требуется Android 10+. Package ID `com.gutkin.frame`, тестовый ключ и формат `project.json` версии 1 сохранены; versionCode увеличен до 4. Обновление устанавливается поверх 0.1.x / 0.2.0. Приватные копии видео и прежний проект остаются на месте. Код предыдущего интерфейса доступен в теге `rn-0.1.1`.

[GitHub Actions](https://github.com/Gutkin/RN/actions/workflows/android.yml) собирает APK в чистом окружении без Node.js, устанавливает прежний APK, затем обновление и запускает инструментальные тесты. Успешные сборки и отчёты доступны также в ветке `android-builds`.

APK подписан тестовым ключом, а не ключом для Google Play. Перед выпуском нужны собственная release-подпись / Play App Signing, проверка текущих требований target SDK и нативных библиотек, испытания на физических устройствах, политика конфиденциальности и оформление магазина.

## Сборка

JDK 17, Android SDK platform 35 / build-tools 35.0.0. Версии Gradle, AGP, Kotlin, Compose и Media3 закреплены в конфигурации. Node.js, npm, Metro и NDK не требуются.

```sh
cd android
./gradlew assembleRelease testReleaseUnitTest assembleReleaseAndroidTest
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.

На подключённом устройстве или эмуляторе:

```sh
cd android
./gradlew connectedReleaseAndroidTest
```

Проверки охватывают ограничения, расчёт фрагментов, коллекции шаблонов, кнопки и слайды, реальные инструменты редактора, плеер, импорт/экспорт H.264 и HEVC и совместимость старого JSON-проекта. Дополнительный экспорт проверяется по пикселям декодированного кадра: вписывание, чёрно-белый фильтр и коралловый текст снизу. Тестовые видео — синтетические материалы в `androidTest/assets`; они не входят в пользовательский APK. Примеры фотографий — отдельная чистая иллюстрация в `drawable-nodpi`.

## Код

- `FrameApp.kt` — каталог, проекты, настройки, экспорт и навигация.
- `VideoEditor.kt` — редактор, лента кадров, инструменты и ExoPlayer.
- `FrameViewModel.kt` — состояние, импорт, сохранение и экспорт через корутины.
- `Models.kt` — шаблоны, данные видео и совместимое атомарное хранение проекта.
- `video/VideoEngine.kt` — независимый от интерфейса видеодвижок: метаданные, проверка лимитов, импорт и экспорт.
- `video/VideoStyle.kt` — одинаковые эффекты для предпросмотра и экспорта.
- `video/MediaLimits.kt`, `MediaInputSupport.kt` — ограничения и поддерживаемые кодеки.

Все файлы приложения находятся в `android/app/src/main/java/com/gutkin/frame/`.

## Облачная среда

Используйте существующий checkout `/workspace/RN`: каждая задача уже изолирована, Git worktree без запроса пользователя не нужен. Подготовка: `python3 scripts/setup-cloud.py`, затем `. /workspace/tooling/java-env.sh`. Скрипт устанавливает инструменты в `/workspace/tooling` с проверкой контрольных сумм и поддержкой доверенных CA среды. Сервисы для автономного APK запускать не требуется.
